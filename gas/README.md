# はやし数学ポータル（Google Apps Script 版）

学校の端末では `hayashi-math-portal-jodkgk.github.io` が、教育委員会のフィルタで「不確定サイト」としてブロックされます。
計算王（Apps Script）は開けるので、同じポータルを Apps Script からも出せるようにしました。

- ポータルの元は今までどおり GitHub です。更新の手順（`site/` を直して push）は変わりません。
- Apps Script が 10 分ごとに GitHub のポータルを読みに行き、自動で取りこみます。
- プリントの画像は、Apps Script が個人の Google ドライブのフォルダ「はやし数学ポータル（画像の写し）」に自動で写します。
- 学校アカウントのドライブ（教科書データ・AI自動作成プリント）にはさわりません。

## はじめの設定（1 回だけ・10 分ほど）

計算王と同じ**個人の Google アカウント**で行います。

1. https://script.google.com を開き、「新しいプロジェクト」を作ります。名前は「はやし数学ポータル」にします。
2. 最初からある `コード.gs` の中身を全部消し、このフォルダの `Code.gs` の中身を全部貼りつけて保存します（Ctrl+S）。
3. 上の関数の選択で `setup` を選び、「実行」を押します。
   - 「承認が必要です」と出たら、個人アカウントを選びます。
   - 「このアプリは Google で確認されていません」と出たら、「詳細」→「はやし数学ポータル（安全ではないページ）に移動」→「許可」の順に押します。
   - Apps Script がドライブにフォルダを作り、GitHub を読むために使う許可です。
4. 下の実行ログに「取りこみ完了：画像 ○ 枚」と出るまで待ちます（はじめは 2〜3 分）。
   - 「時間切れ」と出たときは、10 分後に自動で続きをします。すぐ終えたいときは `syncNow` を選んで実行します。
5. 右上の「デプロイ」→「新しいデプロイ」を押します。
   - 歯車から「ウェブアプリ」を選びます。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押し、出てきたウェブアプリの URL（`https://script.google.com/macros/s/…/exec`）をコピーします。
6. 生徒の端末でその URL を開き、次の 4 つを確かめます。
   - ホームが出る
   - プリントの画像が出る
   - 印刷できる
   - スクリーンモードが使える
7. 確かめられたら、Classroom に貼ってあるポータルのリンクをこの URL に差しかえます。

## ふだんの更新

- 今までどおり GitHub に push するだけです。Apps Script のページには最長 10 分ほどで反映されます。
- index.html を変えずに画像だけを直したときは、反映まで最長 1 時間かかります。すぐ反映したいときは、Apps Script で `syncNow` を実行します。
- 生徒のブラウザに前のページが残っていたら、再読み込み（F5）してもらいます。

## 注意

- ドライブの「はやし数学ポータル（画像の写し）」フォルダは消さないでください。中の画像は「リンクを知っている全員が閲覧可」になっています。GitHub で公開している画像と同じものです。
- 画像を置きかえるたびに、古い画像はドライブのごみ箱に入ります。ごみ箱の画像は 30 日で自動で消えます。
- `Code.gs` を直したときは、「デプロイ」→「デプロイを管理」→ 鉛筆のボタン → バージョン「新バージョン」→「デプロイ」の順に押します。この手順なら URL は変わりません。

## 困ったとき

- **ページが「準備中です」のまま**：1 回目の取りこみが終わっていません。`syncNow` を実行して、実行ログを見ます。
- **画像だけ出ない**：`Code.gs` の `IMG_URL` を `'https://drive.google.com/thumbnail?id={id}&sz=w1600'` に変えて保存し、`syncNow` を実行します。
- **10 分たっても更新されない**：左の「トリガー」に `sync`（10 分ごと）があるか確かめます。なければ `setup` をもう一度実行します。

## clasp で送るとき（パソコンの Claude Code）

計算王と同じように clasp で `Code.gs` を送れます。

1. `site/gas/` に `.clasp.json` を作る（GitHub には上げない。`.gitignore` に入っています）
   ```json
   {"scriptId": "<Apps Script のプロジェクトの URL の /projects/ と /edit のあいだ>", "rootDir": "."}
   ```
2. `site/gas/` で `clasp push`（`Code.gs` と `appsscript.json` が送られる。README.md は送られない）
3. 公開中のウェブアプリを新しくする：`clasp deployments` で ID を調べて `clasp deploy -i <その ID>`（URL は変わらない）

はじめの `setup` の実行と許可は、エディタで 1 回だけ行います（clasp からはできません）。
